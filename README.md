# Mobile-Phones-Website
A responsive mobile phone showcase and comparison website built with HTML, CSS, and JavaScript
Mobile-Phones-Website
A modern, responsive, and feature-rich web application for browsing the latest smartphones, comparing specifications, and finding the best deals.
✨ Features
- 📱 Latest Smartphone Catalogue: Display top mobile brands with real-time pricing and specifications.
- 🔍 Search & Filter: Filter phones by brand, budget, and specs (RAM, Storage, Battery).
- ⚖️ Smart Comparison Tool: Side-by-side comparison of two or more smartphones.
- 🎯 Category Highlights: Dedicated sections for Gaming Phones, Camera-centric Devices, and Budget Picks.
- 📱 Fully Responsive: Optimized layout for Mobile, Tablet, and Desktop screens.
🛠️ Tech Stack
- Frontend: HTML5, CSS3 (Flexbox & Grid), JavaScript (ES6+)
- Icons & Fonts: FontAwesome / Google Fonts
